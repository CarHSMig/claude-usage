# Horas de IA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record exact AI-execution time per account/project/session via Claude Code command hooks, import past exact time from transcripts, store it in SQLite, and show it in a drawer under the usage rings.

**Architecture:** A tiny `UsoClaudeHook` executable appends sanitized hook events to `events/<account>.jsonl`. The app ingests those lines into SQLite (`events` table), rebuilds each touched session's intervals with a pure state machine (`buildIntervals`), and answers report queries with a pure aggregator (`HoursReport`). History import turns `turn_duration` transcript entries into intervals. A settings installer adds/removes our hook entries in both `settings.json` files.

**Tech Stack:** Swift 6.1, SwiftPM, SwiftUI/AppKit, system `SQLite3`, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-26-ai-hours-design.md` (extends `docs/superpowers/specs/2026-10-26-usage-widget-design.md`)

## Global Constraints

- Hook prints **nothing** to stdout/stderr and always exits 0; no network, no SQLite, no git in the hook.
- Hook persists only: `ts`, `hook_event_name`, `session_id`, `cwd`, `transcript_path`, `tool_name`, `notification_type`. Never the prompt or any message content.
- Data dir: `~/Library/Application Support/UsoClaude/` → `events/<label>.jsonl`, `usage.sqlite`.
- Hook command: `'/Applications/Uso Claude.app/Contents/MacOS/uso-claude-hook' --account <label>`; type `command`; matcher `""`.
- Settings edits: backup `settings.json.bak-usoclaude-<unix timestamp>` first; never touch existing entries; idempotent install; uninstall removes only entries whose command contains `uso-claude-hook`.
- Pause signals: `PermissionRequest`; `Notification` with `notification_type == "permission_prompt"`; `PreToolUse` with `tool_name` `AskUserQuestion` or `ExitPlanMode`.
- Abandon timeout: 30 min without events closes an open interval at last activity.
- Within a session intervals are unioned; across sessions they sum (user-confirmed).
- Week = Monday–Sunday, local time zone. Day view = 00:00–23:59 in 24 hourly buckets.
- Import only `turn_duration` with `isSidechain != true`, interval `[timestamp − durationMs, timestamp]`, only before that account's `hooks_installed_at` (or all, if hooks not installed yet — re-import is blocked once marked done; see Task 4 ruling).
- Colors: `claude` blue `#6aa7ff`, `proteo` purple `#c18cff`.
- No git repo: skip commit steps.

## Review Focus

1. Esc-interrupted turn followed much later by a new prompt — the gap must not count (test in Task 2).
2. Turn crossing midnight — split across two days/hours exactly (test in Task 5).
3. Hook stdin with a huge prompt / malformed JSON — writes nothing or a sanitized line, never prints, exits 0 (test in Task 1).
4. `settings.json` already containing our hook (re-install) or containing comments-free but unusual shapes (`hooks` missing entirely) — no duplicate, no data loss (test in Task 6).
5. History file with a `turn_duration` after hooks were installed — not imported twice (test in Task 4).

**Interfaces:**

  - `public func buildIntervals(_ events: [HookEvent], now: Date) -> [AIInterval]` — events of ONE session, any order (sorted by `ts` inside).

Rules (spec §2): `UserPromptSubmit` starts (closing a dangling one at its last activity event); pause signals close at their `ts`; any activity event (`PreToolUse` non-waiting, `PostToolUse`, `PostToolUseFailure`, `SubagentStart`, `SubagentStop`) after a pause reopens at its `ts`; `Stop` closes; `SessionEnd` closes at last activity; open interval whose last activity is > 30 min before `now` closes at last activity; otherwise stays open (`end == nil`). "Last activity" = latest `ts` among start/activity events of the current interval.
